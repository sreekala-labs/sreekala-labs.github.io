Data is central to most applications today. Small amounts of data which can be stored and processed on a single machine are often fairly easy to deal with. 
However, as the data volume increases, the need for a distributed system across multiple machines, introduces many challenges. 

There are two types of systems:
* Compute-intensive Systems. (Very Large Compuration)
* Data Intensive Systems. (We care about storing and processing large data volumes, managing the data, ensuring consistency and concurrency.


| Applications | Purpose| 
|---|---|
| Databases | Store data so that they can find it later | 
| Caches | Speeds up reads | 
| Search Indexes| Search data by keyword or filter it in various ways | 
| Stream Processing | Handles events and data changes as soon as they occur| 
| Batch Processing | Periodically handle a large amount of accumulated data | 

* Operational Systems: Consists of backend and data infrastructure. 
* Analytical Systems : Serves the needs of business analysts and data scientists. Read Only Copy of the Database.

---

OLTP Vs OLAP : 
* Online Transaction Processing vs Online Analytical Processing. 
* Ideally, you will have large amounts of small queries for OLTP. Few Queries for OLAP but complex ones. 
* Database size varies from GB to TB for OLTP and TB to PB for OLAP.

---
Data Warehouse: 

* The separate database which is used to run analytics.
* Contains read only copy of the data from all various OLTP systems.
* The data is processed via the concept of ETL - Extract-Transform-Load.
* ETL - Extract the data from different parts of the system. (Example: Sales DB, Inventory DB). Then the data is transformed accordingly in the
  data warehouse and then loaded into then data warehouse.
* Data warehouse often uses relational data model that is queried through SQL.
* If we were traing a ML model, then we need a custom solution to extract the data and convert DB Table into vector or a matrix of numerical values called
  features.(Data warehouse Less Suited here.)
* Using NLP on a textual data(Data warehouse Less Suited here.)
* Data Scientints prefer using Python or other programming language such as R, data analysis libraries such as pandas and sci-kit learn to work with data warehouse.

Data Lake: 

* Storing raw data(Sushi prinicple) so that different systems can use the data however they want. The data is stored in raw format(object storage),   

Distributed Systems: 

* A system that involves several machines communicating via a network.
* Every request and API call that traverses the network needs to deal with the possibility of failure.
  The network may be interrupted, or the service may be overloaded or crash, and therefore any request may time out without receiving a response.
  In this case, we don’t know whether the service received the request, and simply retrying it might not be safe.
* Performing a task on a single machine is often much simpler and cheaper than setting up a distributed system.
* Used when:
  1. Inherit Distribution
  2. Scalability
  3. Elasticity
  4. Communication between different services.
  5. Legal Compliance
  6. Sustainability
  7. Specialized Hardware
  8. Fault Tolerance or high availability
